# Leafclutch

**Implemented only Home and About Us**

Leafclutch is a modern web application built using **React**, **TypeScript**, and **Vite** for fast development and builds. The app is styled using **Tailwind CSS**, offering a clean and responsive UI.

> Live Demo: [https://leafclutch-by-nishantbk.vercel.app/](https://leafclutch-by-nishantbk.vercel.app/)

---

## 🛠️ Features

- Fast development and build process with **Vite**.
- Clean and responsive design using **Tailwind CSS**.
- **React** for building interactive UI components.
- Written in **TypeScript** for static typing and better developer experience.
- Easy-to-understand and maintainable project structure.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have the following installed:

- **Node.js** (LTS version is recommended)
- **npm** (comes with Node.js)

### Steps to Run Locally

1. **Clone the repository**:

   ```bash
   git clone https://github.com/nishantbk311/Leafclutch.git
   cd Leafclutch
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm run dev
   ```

   The app will be available at `http://localhost:5173` in your browser.

---

## 💻 Scripts

The following commands are available for managing the app:

- `npm run dev`: Start the development server (default port is `5173`).
- `npm run build`: Build the app for production.
- `npm run preview`: Preview the production build locally.
